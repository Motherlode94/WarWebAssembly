Démarrage rapide

Le runtime charge des octets WebAssembly via les API natives du navigateur. Il ne compile pas encore de source C++, Rust ou WAT.

git clone https://github.com/Motherlode94/WarWebAssembly.git
cd WarWebAssembly
npm test
import { loadModule } from './src/runtime.js';
const result = await loadModule(bytes, {});
console.log(result.exports);

API et erreurs
loadModule(bytes, imports = {})
  → Promise<{ module, instance, exports }>
Accepte ArrayBuffer ou une vue typée. Compile puis instancie le module. Les imports sont explicitement fournis par l'appelant.
CompileError
Module binaire invalide ou incompatible.
LinkError
Import manquant ou incompatible.
RuntimeError
Erreur durant l'exécution, par exemple un accès mémoire hors limites.
Le laboratoire exécute uniquement des modules intégrés et connus. Aucun téléversement de code arbitraire n'est activé.
